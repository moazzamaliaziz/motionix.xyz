The single biggest decision we made when building Motionix was that no tool on the site should ever upload your file to our server. There are three reasons we held the line, and they're worth understanding before you trust an image tool with anything private.

## What runs client-side

Picture tools used to mean "send your file to a worker, wait, send it back." That pattern has costs:

- **Round-trip latency.** Even on a fast fiber link, a 200 MB video between your browser and a server takes 10-30 seconds just to transfer.
- **Privacy.** Once a file leaves your device, you lose control over it. Most services delete it eventually — but "eventually" is doing a lot of work.
- **Cost.** Server-side processing means GPU servers, egress fees, and scaling headaches. Those costs get passed to users somehow — through ads, subscriptions, or data harvesting.

## How browser-based processing works

Modern browsers expose APIs that were previously only available to native apps:

- **Canvas API** — image resizing, cropping, format conversion, pixel manipulation
- **WebGL / WebGPU** — GPU-accelerated image processing
- **ONNX Runtime Web** — run AI models (background removal, object detection) entirely in the browser
- **WebCodecs** — hardware-accelerated video encoding and decoding

These APIs are built into Chrome, Firefox, Safari, and Edge. No plugins, no downloads, no extensions.

## The privacy guarantee

When we say "your file never leaves your device," we mean it technically:

1. The JavaScript code runs in your browser's sandbox.
2. The file is read from your local filesystem via the File API.
3. Processing happens in memory using Canvas, WebGL, or ONNX Runtime.
4. The result is offered as a download via the Blob API.

At no point does `fetch()` or `XMLHttpRequest` send your file to our servers. You can verify this by opening your browser's Network tab while using any tool.

## The trade-off

Browser-based processing has real limits:

- **File size.** Browser tabs have memory limits (typically 2-4 GB). A 4 GB video would crash most tabs.
- **Speed variance.** A MacBook Pro M3 is 10x faster at ONNX inference than a 2018 Android phone.
- **Feature gaps.** Some tasks (like multi-pass video encoding) are still better on a server.

We're transparent about these limits. Each tool page shows its maximum file size and browser compatibility.
