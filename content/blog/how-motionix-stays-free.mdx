A question we get a lot: how can you offer these tools for free? The short answer is that most of the work happens on your device, not on ours. The long answer is more interesting — and useful for any solo founder figuring out where to spend their hosting budget.

## The cost floor we're working with

Our entire production environment breaks down into one line item: a server that costs roughly $20/month. That's it. We don't pay S3 egress, we don't pay a worker fleet, we don't pay for GPUs. We do pay for a domain, and a modest amount for analytics that we'd skip if push came to shove.

## Why browser-based processing is free

The key insight: if the computation happens on the user's device, we don't pay for it. Modern browsers can:

- Run AI models via ONNX Runtime (background removal)
- Encode/decode video via WebCodecs (video compression)
- Process images via Canvas API (resizing, cropping, format conversion)

The user's CPU/GPU does the work. We just deliver the code.

## What we actually pay for

| Item | Monthly cost |
|------|-------------|
| Vercel hosting | $0 (free tier) |
| Domain (motionix.xyz) | $1.50 |
| Ahrefs analytics | $0 (free tier) |
| Supabase database | $0 (free tier) |
| Total | ~$2/month |

## What we don't pay for

- **GPU servers.** We don't have any. All AI runs in the browser.
- **CDN egress.** Vercel's free tier covers our traffic.
- **Worker fleets.** No server-side processing means no workers.
- **Database scaling.** Supabase free tier handles our needs.

## The trade-off

Browser-based processing has limits:
- **File size caps.** Browser memory limits how large files can be.
- **Speed.** User devices vary. A 2024 laptop is 10x faster than a 2015 phone.
- **Features.** Some tasks (like video background removal) need server-side processing.

We're honest about these limits. Each tool page states its maximum file size and supported formats.

## For other founders

If you're building a tool site, ask yourself: does this need a server? The answer is often no. Browser APIs are more capable than most people realize. You can build a profitable SaaS on $20/month if the computation happens client-side.
