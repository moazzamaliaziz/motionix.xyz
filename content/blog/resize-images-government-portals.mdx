Government portals are notoriously strict about image dimensions and file sizes. Upload the wrong size and you get a cryptic error message. Here's how to match their requirements exactly.

## Common government portal requirements

| Portal | Photo size | File size | Format |
|--------|-----------|-----------|--------|
| US passport | 600×600 px | No limit | JPEG |
| US visa | 600×600 px | 240 KB max | JPEG |
| Indian passport | 350×350 px | 20-50 KB | JPEG |
| UK passport | 600×750 px | No limit | JPEG/PNG |
| Schengen visa | 413×531 px | No limit | JPEG |
| US Green Card | 600×600 px | 240 KB max | JPEG |
| India Aadhaar | 350×350 px | 20-50 KB | JPEG |

## Step-by-step process

1. **Check the portal's requirements.** Look for "photo specifications" or "image requirements" on the portal.
2. **Note the exact dimensions.** Width × height in pixels.
3. **Note the file size limit.** In KB or MB.
4. **Note the format.** JPEG is almost always required.
5. **Use a resizer tool.** Upload your photo, enter the exact dimensions, download the result.

## Getting the file size right

Some portals have very tight file size limits (India: 20-50 KB). To hit these:

1. Resize to the required dimensions first.
2. Save as JPEG with quality 70-80.
3. Check the file size.
4. If too large, reduce quality to 60-70.
5. If too small, you can increase quality for better appearance.

## Common errors and fixes

| Error | Cause | Fix |
|-------|-------|-----|
| "Image too large" | File exceeds KB limit | Compress with lower quality |
| "Invalid dimensions" | Wrong pixel size | Resize to exact spec |
| "Invalid format" | PNG or BMP instead of JPEG | Convert to JPEG |
| "Image too small" | Resolution too low | Use a higher-res source photo |

## Tips for success

- **Start with a high-resolution photo.** It's easier to shrink than to enlarge.
- **Use the rear camera.** Selfie cameras have wider distortion.
- **Plain background.** White or light gray, no patterns.
- **Even lighting.** No harsh shadows on face or behind head.
