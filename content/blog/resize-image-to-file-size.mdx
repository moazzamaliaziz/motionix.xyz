Government portals, scholarship forms, and visa applications often have strict file size limits. "Upload a photo under 50 KB" is a common requirement. Here's how to hit that target exactly.

## Why file size limits exist

- **Server storage.** Millions of uploads × large files = expensive storage.
- **Bandwidth.** Smaller files transfer faster, especially on slow connections.
- **Processing.** Smaller files are faster for the portal to process and store.
- **Fairness.** Size limits prevent abuse from users uploading massive files.

## How to resize to a target KB

1. **Start with the right format.** JPEG is almost always smaller than PNG for photos.
2. **Resize dimensions first.** A 4000×3000 photo will never be 50 KB. Resize to 600×800 or smaller.
3. **Compress with a quality target.** Start at quality 80 and adjust.
4. **Check the file size.** If still too large, reduce quality or dimensions further.

## Common size requirements

| Use case | Typical limit | Recommended approach |
|----------|---------------|---------------------|
| Indian passport | 20-50 KB | 350×350 px, JPEG quality 70-80 |
| US visa | 240 KB | 600×600 px, JPEG quality 85 |
| Scholarship forms | 50-100 KB | 400×500 px, JPEG quality 75 |
| Government portals | 50-200 KB | Resize to spec, compress to target |
| Job applications | 100-500 KB | 600×800 px, JPEG quality 80 |

## Step-by-step example

Target: 50 KB maximum, passport photo

1. Resize to 350×350 pixels
2. Save as JPEG, quality 75
3. Check file size — if 45 KB, you're good
4. If 60 KB, reduce quality to 65
5. If 30 KB, you can increase quality for better look

## Tools that support file size targets

Browser-based tools that let you specify a target KB are the easiest option. Upload the photo, type "50 KB" as the target, and download the result.

## Common mistakes

- **Resizing dimensions but not compressing.** A 350×350 PNG can still be 200 KB.
- **Compressing too much.** Below quality 50, JPEG artifacts become visible.
- **Not checking the result.** Always verify the file size after processing.
