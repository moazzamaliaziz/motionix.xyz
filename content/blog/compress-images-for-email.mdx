Gmail caps at 25 MB. Outlook at 20 MB. Most other providers at 10 MB. A single phone photo can be 5-15 MB. Here's how to compress images to fit.

## Email attachment limits

| Provider | Limit |
|----------|-------|
| Gmail | 25 MB |
| Outlook | 20 MB |
| Yahoo | 25 MB |
| ProtonMail | 25 MB |
| Apple Mail | 20 MB |

## Step-by-step compression

1. **Check the original size.** Right-click the file → Properties (Windows) or Get Info (Mac).
2. **Open an image compressor.** Browser-based tools process locally — no upload.
3. **Set a target.** If the limit is 25 MB and you have 3 images, target 7 MB each.
4. **Compress and download.** The tool shows you the before/after size.
5. **Attach to email.** The compressed file is ready to send.

## Quality settings for email

- **Photos:** Quality 75-85 is plenty. Email recipients view on screens, not prints.
- **Screenshots:** Use PNG compression instead of JPEG — text stays sharp.
- **Documents:** Scan as JPEG at quality 80, not TIFF or BMP.

## Multiple images

If you need to send 10+ images:
- Compress each one individually
- Or create a ZIP file (though this doesn't compress JPEGs much)
- Or use a cloud link (Google Drive, Dropbox) instead of attachments

## Common mistakes

- **Sending BMP or TIFF.** These are uncompressed — always convert to JPEG first.
- **Compressing too much.** Below quality 60, JPEG artifacts become visible.
- **Not checking the result.** Always preview the compressed image before sending.
