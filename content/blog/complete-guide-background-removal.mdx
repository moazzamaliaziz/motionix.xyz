Removing the background from a photo used to mean hours in Photoshop with the pen tool. In 2026, it takes about two seconds in a browser tab. This guide covers every approach — when to use each one, what the AI models actually do, and how to get clean results on the first try.

## How background removal actually works

Modern background removal tools use a segmentation model — a neural network trained to separate foreground from background pixel by pixel. The most common model in web-based tools is ISNet (Interference Suppression Network), which runs entirely in your browser via ONNX Runtime.

The model downloads once (~30 MB), caches in your browser, and processes images locally. No upload, no server, no waiting.

## When to use browser-based tools

Browser-based removal is ideal when:

- **Privacy matters.** Client photos, product shots, medical images — anything you don't want on a server.
- **Speed matters.** No upload round-trip means results in 1-2 seconds after model warm-up.
- **Volume is moderate.** For a handful of images per day, browser tools are perfect.

## When to use server-based tools

Server-based tools make sense when:

- **Batch processing.** Hundreds or thousands of images need consistent output.
- **Video backgrounds.** Browser tools can't handle video — you need a server.
- **Ultra-fine hair detail.** Server models with larger memory budgets can handle edge cases better.

## Getting clean results

The quality of your input photo matters more than the tool:

1. **Use even lighting.** Harsh shadows confuse segmentation models.
2. **Plain backgrounds help.** A contrasting background makes the cutout cleaner.
3. **Avoid motion blur.** Sharp edges produce sharp masks.
4. **Face the camera.** Profile shots have more edge ambiguity than front-facing photos.

## Output formats

- **Transparent PNG** — the standard. Preserves alpha channel for layering.
- **White background** — for e-commerce listings, passports, and resumes.
- **Custom color** — for brand-consistent product shots.

## Common mistakes

- **Over-compressing the input.** A 50 KB JPEG has artifacts that create jagged edges.
- **Ignoring the mask preview.** Always check the mask before downloading.
- **Using the wrong tool for hair.** Fine hair needs a model trained on portrait data, not product data.
